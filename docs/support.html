Common issues

The seven problems that come up most, and what to do about each one.

Problem Fix
Haven does not start Make sure Node.js is installed. After installing, restart your computer, then try again.
SSL_ERROR_RX_RECORD_TOO_LONG The browser is trying HTTPS while Haven is running HTTP. Go to http://localhost:3000 and not to https. The guide has the details.
Friends cannot connect They need your public IP address and port 3000. You may need to port forward 3000 on your router, and your firewall has to allow it too.
Voice chat does not work Voice needs HTTPS or localhost. If friends are connecting over the internet without HTTPS, voice will not work in most browsers. Install OpenSSL and restart Haven to turn HTTPS on by itself.
Port 3000 is already in use Another program is on port 3000, or Haven is already running. Close the other terminal window, or restart the machine to free the port.
The page loads but looks broken Hard-refresh with Ctrl+Shift+R, or Cmd+Shift+R on macOS. Cached files sometimes cause this after an update.
GIFs do not work The admin has to set a GIPHY API key. Go to Settings, then Admin, and paste the free key from developers.giphy.com.

Report a bug

Found something broken? Here is what to write down, and where to send it.

What to include

The more detail you give, the faster it can be fixed.

  • What happened?

    Describe what went wrong. "Voice chat disconnects after two minutes" says more than "voice broken".

  • What did you expect?

    What should have happened instead?

  • Steps to reproduce

    What were you doing when it broke? Can it happen again on purpose?

  • Your setup

    Windows, macOS or Linux? Which browser? Are you the host or a guest?

How to report

Email the report Open a GitHub issue

Email is the fastest way to reach the maintainer. GitHub Issues is there as well, if you have an account.

Questions people ask

How do I update Haven?

Take the latest zip from the releases and replace the files. The data, meaning the messages, the accounts and the uploads, is kept in a separate folder, so an update does not touch it.

Where is my data stored?

On Windows it is %APPDATA%\Haven, which you can type into the address bar of File Explorer. On macOS and Linux it is ~/.haven. That folder holds the database, the uploaded files and the settings. The program files are separate from it, so an update does not erase anything.

Can I move Haven to another computer?

Yes. Copy the data folder to the same place on the new machine, then run Haven there. The messages, the accounts and the settings all come across.

Do my friends need to create an account?

They create an account on your server, with a username and a password and nothing else. No email address, no phone number, no third-party sign-up. The account exists only on your machine.

Is voice chat peer to peer?

Yes. The audio goes straight between the participants over WebRTC. The server only relays the signalling, which is the part that connects them. The voice data does not pass through the Haven server.

Can I run Haven all day and all night?

Yes. It is light on resources and will happily sit in the background on any modern computer. People run it on a Raspberry Pi, or on an old laptop they leave switched on.

How do I get HTTPS working?

Install OpenSSL on Windows, or use the package manager of the system on macOS and Linux. Restart Haven, and it generates the certificates and switches to HTTPS by itself. The setup guide has the full instructions.
