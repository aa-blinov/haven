A chat server for a group of people who would rather run it themselves.

One Node.js process serves the web client, the JSON API and the Socket.IO endpoint, and keeps messages, users and settings in a SQLite file on the machine you started it on. Voice calls go from browser to browser over WebRTC, so the audio never passes through the server. Only the host installs anything: everyone else joins from a browser.

git clone https://github.com/aa-blinov/haven.git && cd haven && docker compose up -d

MIT-NC licence. Node.js 18 to 24, or Docker. Windows, macOS and Linux. Every way to run it

Up and running in three steps

There is no config file to write and no account to create with a company. Download it, start it, send the channel code.

  1. Download and unpack

    Take the zip from the downloads and unpack it anywhere. The desktop is fine; it makes one folder.

  2. Start it

    Run Start Haven.bat on Windows or start.sh on macOS and Linux. It installs Node.js if the machine does not have it, installs the dependencies, generates the certificate and opens the browser. Restart the machine after installing Node.js yourself. The first boot takes about thirty seconds.

  3. Share the code

    Register as admin, create a channel, and send the eight-character channel code to the people you want in the room. They open the address in their browser and register there.

Four questions come up before the first message.

  • What does self-hosted mean?

    The chat runs on your computer, not on a company's server. The messages stay in a SQLite file next to it. Your machine is the cloud.

  • Do my friends need to download anything?

    No. They open a link in Chrome, Firefox, Edge or Safari, any modern browser. Zero installs on their side, and it works on a phone.

  • Is it secure?

    HTTPS with a self-signed certificate, bcrypt password hashes, JWT sessions that last seven days, a rate limiter on the login routes and CSP headers. The source is open, so read it.

  • What do I need?

    Windows, macOS or Linux, and Node.js 18 to 24 from nodejs.org, which installs in two clicks. Or Docker, and nothing else.

The certificate is self-signed, so the browser asks once before it opens the page. Voice chat needs a secure origin: it works on http://localhost, and from another machine it needs the HTTPS listener.

Everything you need, nothing you don't

A chat server you control, that asks nobody for an account and that nobody else reads.

  • Only the host downloads

    One person runs Haven on their machine. Everyone else opens a link. No app to install, no store account to create, no app store. A friend can join in thirty seconds from a laptop or a phone.

  • Voice chat, peer to peer

    The audio goes straight between the participants and not through a middleman server. Every participant has a volume slider, and there are mute, deafen, talking indicators and a tone when somebody joins or leaves.

  • Screen sharing and streaming

    Share your screen with anyone in the voice channel. Several people can share at once and the tiles are laid out in a grid. It works for a watch party, for co-working, or for showing a game.

  • Private, with encrypted direct messages

    No cloud, no telemetry, no analytics. Messages live in the SQLite file on the host's machine. Direct messages are sealed with AES-256-GCM from a key pair generated in the browser, so the server cannot read them.

  • Mobile-ready

    The interface adapts to the screen it is on. Channels, direct messages, voice chat and file sharing all work from a phone browser, with nothing to install.

Everything it does

Haven is not a toy. It is a full chat platform with the parts people use every day.

  • Discord import

    Bring a whole Discord server across: every channel, thread, forum post, reaction, pin, attachment and avatar. Paste a token, pick a server, done.

  • Music and video streaming

    Spotify, YouTube and SoundCloud listen-together with synced playback and a seek bar. Share an audio file or screen-share a movie, and everyone hears and sees it at the same time.

  • Rich chat

    Real-time messaging, image uploads, typing indicators, message editing, replies, emoji reactions, @mentions, and editable channel names with collapsible sub-channels.

  • Voice chat

    Peer-to-peer audio, with a volume slider per participant, mute, deafen, noise suppression and talking indicators.

  • Screen sharing

    Multi-stream support, a tiled grid layout, a resizable viewer, and several people sharing their screens at once.

  • Encrypted direct messages

    End-to-end encrypted with ECDH and AES-256-GCM. The keys sync across devices through password wrapping. Not even the host can read them.

  • Twenty-seven themes

    Haven, Discord, Matrix, Tron, Halo, Lord of the Rings, Cyberpunk, Dark Souls, Elden Ring, Minecraft, Dracula, Nord, Fallout, CRT, Win95, RGB and more. A file named something.theme.css in the themes folder adds another.

  • GIF search

    Search and send GIFs inline, powered by GIPHY. The /gif slash command does the same from the message box, and the admin turns it on with one key.

  • File sharing

    Share documents, images, audio, video and archives up to the size the admin sets, 25 MB by default. Audio and video get an inline player.

  • Link previews

    A pasted URL is fetched on the server and its Open Graph title, description and thumbnail are shown.

  • Slash commands

    Twenty-one of them, from /shrug to /roll 2d20, each with autocomplete and a description.

  • Message search

    Ctrl+F searches any channel. The matches are highlighted, and the result jumps to the message.

  • Pinned messages

    Admins pin the messages that matter. A panel lists every pin in the channel.

  • Moderation

    Kick, a timed mute, ban, delete a user, roles with per-channel permissions, a registration whitelist, slow mode, and an automatic cleanup of old messages and files.

  • Multi-server

    Add the servers your friends run to the sidebar, with a live online and offline indicator.

  • Notification sounds

    Five tones, with a volume per channel and a switch to turn them off where they are not wanted. Unread badges survive a reload.

  • Games

    Shippy Container, Flight, Learn to Fly 3, Bubble Tanks 3, Tanks, Super Smash Flash 2, and a list of .io games. The canvas game keeps its leaderboard in the database, and the Flash games run through Ruffle.

  • Join codes

    Every channel carries an eight-character code. An admin decides whether the code is public or private, whether it stays the same or rotates on a timer or on a join count, and a server-wide code joins every top-level channel at once.

  • Two-factor authentication

    TOTP with backup codes, and recovery codes for a lost password. Both are optional, and no email address is ever asked for.

  • Bot webhooks

    An admin creates a webhook for a channel and posts to it with a 64-character token. The message lands in the channel with the name and the avatar of your choosing.

  • Plugins

    A file named something.plugin.js in the plugins folder becomes a plugin. The settings panel lists them, and each person turns them on in their own browser.

Get Haven

The server

The server is one zip file. Unpack it, start it, and the browser opens.

Download v2.7.4 (.zip) View the source

Version 2.7.4. Windows, macOS and Linux. The tagged archives are published in the upstream repository, ancsemi/Haven. This page is published from aa-blinov/haven.

With Docker

The compose file builds the image from this checkout, keeps the data in the haven_data volume, and publishes port 3000 for HTTPS plus port 3001 for the HTTP redirect.

$ git clone https://github.com/aa-blinov/haven.git
$ cd haven
$ docker compose up -d
  Local:   https://localhost:3000
# the HTTP redirect listens on 3001

The other routes

Route Command What it is for
Windows launcher Start Haven.bat Installs Node.js if it is missing, installs the dependencies, generates the certificate and opens the browser.
Linux and macOS launcher chmod +x start.sh && ./start.sh The same steps in a shell.
Web installer chmod +x install.sh && ./install.sh A wizard in the browser that asks for the server name and the admin password. It binds to 127.0.0.1 only.
Plain Node npm install && node server.js Nothing around it: no certificate, no launcher, no wizard.
